Keyboard shortcuts

Each mode uses two keys. Hold Key 1 and press Key 2 to start recording. Press the same combo again to stop.

How it works: Hold Key 1 and press Key 2 to start recording. Press the same combo again to stop.

Tip: "Green text" is what you use in the hotkeys.

Modifier keys (Key 1) — left and right side both work:

  • cmd — Command key on Mac, Windows key on Windows.
  • ctrl — Control key on both Mac and Windows.
  • shift — Shift key on both Mac and Windows.
  • option — Option key on Mac, Alt key on Windows.

Keys you tap (Key 2):

  • Letters: a through z.
  • Numbers: 0 through 9.
  • Function keys: f1 through f12.
  • Common: space, tab, enter, backspace, escape, capslock.
  • Symbols: minus (-), equal (=), tilde (`), leftbracket ([), rightbracket (]), semicolon (;), quote ('), backslash (\), comma (,), dot (.), slash (/).
Permissions (Mac and Windows)

macOS — Click each button, then allow Voice Keys (or voicekeys):

  • In each of these 3 macOS sections, turn Voice Keys (or voicekeys) ON: Accessibility, Input Monitoring, and Microphone.
  • If you started Voice Keys from Terminal or VS Code, turn that app ON in the same section too.
  • After changing permissions, fully quit and reopen Voice Keys.

Windows 11:

  • Go to Settings > Privacy & security > Microphone.
  • Turn on Microphone access and Let desktop apps access your microphone.
  • Fully quit and reopen Voice Keys.

Windows – pin tray icon to taskbar:

  • By default Windows hides the tray icon behind the ^ arrow.
  • Go to Settings > Personalization > Taskbar > Other system tray icons and toggle voicekeys.exe on.

Deepgram API Key

Voice Keys uses Deepgram for speech-to-text. You need a free API key to get started:

  1. Create a free account at console.deepgram.com.
  2. Go to API Keys and click Create a New API Key.
  3. Copy the key and paste it above.

Tip: If you want to see usage metrics (minutes used, spend, balance) inside this app, create the key with Admin permissions.
