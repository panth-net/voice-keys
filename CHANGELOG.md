# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-07-30

Initial public release.

- Push-to-talk transcription in two modes: paste into the focused app, or copy
  to the clipboard.
- Tray/menu-bar resident with an embedded settings window.
- Configurable two-key hotkeys, language, and Deepgram model.
- Deepgram usage and balance reporting, including per-month history.
- macOS, Windows, and Linux (X11) support.
